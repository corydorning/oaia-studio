Credits & setup

Credit balance is managed in OpenAI Billing; this app does not have live balance access.

OpenAI uses free credits first. Existing purchased credits can be used after those run out. This app cannot buy credits or enable recharge.

Every studio on this Mac shares the saved API key and credit balance. Each has its own history and one-image-at-a-time queue.

The API key is stored in macOS Keychain as “Local Image Studio OpenAI API”.

For a one-day key, create a replacement before the old key expires. Open Configure OAIA API Key.command in the app folder, paste the replacement into its hidden prompt, then choose Check connection. All studios use the new saved key on their next request.
